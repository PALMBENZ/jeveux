☁️ Synchronisation cloud (partage Daji ↔ Bisi)

Colle ci-dessous l'URL de ton Web App Apps Script (voir la marche à suivre plus bas). Tout changement sera automatiquement synchronisé vers Google Sheets, accessible aux deux PC.

📘 Marche à suivre (5 min, une seule fois)
  1. Crée un Google Sheet (Drive → Nouveau → Google Sheets).
  2. Dans ce sheet : Extensions → Apps Script.
  3. Efface le code par défaut et colle le script ci-dessous (bouton "Copier").
  4. Clique sur Déployer → Nouveau déploiement → Type : Application Web.
  5. Description : "Commercial Daji Bisi" · Exécuter en tant que : Moi · Accès : Tout le monde → Déployer.
  6. Autorise le script quand demandé (avec le compte Google qui possède le Sheet).
  7. Copie l'URL de l'application Web (se termine par /exec).
  8. Colle l'URL dans le champ ci-dessus + Enregistrer. Idem sur le PC de Bisi (même URL).
